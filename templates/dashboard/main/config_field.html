{# Reusable configure-field renderer (shared across every module form). Renders the INNER content of a `.field-basic` wrapper (the wrapper + grid column stays in each form so per-form layout is preserved). Switches on `field.type`; when omitted it is inferred for backward compatibility (a `select` key -> select, a `table` key -> table, otherwise text). Supported types: text (default), number, password, select, checkbox, date, color, table, file, generate, divider. color : native colour picker, value kept as #rrggbb (`default` = initial colour, #ffffff). file : uploads straight to `field.upload` (handled in project.js) and keeps only the returned filename in a hidden input named `key`. With `field.remove` (a /api/... route) a remove button appears next to the stored file name and POSTs {id, kind} to it (project.js). generate : readonly input + button that POSTs `field.generate` for a fresh value. table : `field.column_options[]` renders that column as a select. `field.help` adds a small hint under any input.
